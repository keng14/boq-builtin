# BOQ ตู้บิวท์อิน

เว็บแอปออกแบบตู้บิวท์อิน (ตู้ล่าง ตู้แขวน ตู้สูง) ผังตรง / L / U ดูโมเดล 3D, 2D, ISO และ X-ray แล้วได้รายการตัด BOQ การวางชิ้นงานบนแผ่นไม้ และใบเสนอราคาทันที ใช้บนมือถือได้ และติดตั้งเป็นแอปบนหน้าจอโฮมได้ (PWA ใช้ออฟไลน์ได้หลังเปิดครั้งแรก)

**เปิดใช้:** `https://keng14.github.io/boq-builtin/` (หลังเปิด GitHub Pages ตามขั้นตอนด้านล่าง)

## ทำอะไรได้บ้าง

- **โมเดล:** ผังตรง / L / U, ลิ้นชักปรับระยะดึงทีละชั้น, ตู้แขวน, ตู้สูง (ช่องตู้เย็น / ตู้เตาอบ / ตู้เก็บของ), อ่างล้างจาน 1–2 ใบ, backsplash, ช่องเครื่องล้างจาน
- **มุมตู้:** คำนวณแผ่นปิดมุมกันลิ้นชักและบานชนกัน, ช่องที่อยู่หลังขาตู้ (มุมอับ) ไม่คิดบานเปิด
- **BOQ:** สรุปต้นทุน, ราคาต่อหน่วยแก้ได้, รายการตัดพร้อมรหัสชิ้นงานและด้านปิดขอบ, CSV
- **วางแผ่นไม้:** MaxRects ล็อกทิศลายไม้ได้ บอกจำนวนแผ่นที่ต้องสั่ง
- **ใบเสนอราคา:** กำไร %, ส่วนลด, VAT 7%, งวดชำระ, ภาพ 3D และแปลนอัตโนมัติ, ดาวน์โหลด .html หรือพิมพ์เป็น PDF
- **ลูกค้า:** ลิงก์ดูอย่างเดียว และไฟล์หน้าลูกค้า .html (ไม่มีข้อมูลต้นทุนในลิงก์หรือไฟล์)
- **โปรเจกต์:** เก็บหลายโปรเจกต์ในเบราว์เซอร์ ทำสำเนา ส่งออก/นำเข้า JSON
- **Blender:** ส่งออก .json แล้วนำเข้าใน add-on v4.9.1 (`blender/`)
- **ภาษา:** ไทย / อังกฤษ, โหมดมืด

## ไฟล์ใน repo

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (ฝังตัวคำนวณไว้แล้ว ไม่ต้อง build) |
| `engine.js` | ตัวคำนวณ BOQ แยกไฟล์ ไว้อ่านหรือใช้ต่อในโปรเจกต์อื่น (Node/เบราว์เซอร์) |
| `sw.js`, `manifest.webmanifest`, `icons/` | ทำให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้ |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตรงๆ |
| `blender/` | Blender add-on v4.9.1 (ติดตั้งผ่าน Preferences > Get Extensions > Install from Disk) |

## เปิด GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
3. รอ 1–2 นาที แล้วเปิด `https://keng14.github.io/boq-builtin/`

## อัปเดตแอป

แทนที่ `index.html` ด้วยเวอร์ชันใหม่ แล้วแก้ `VERSION` ใน `sw.js` (เช่น `boq-v6.4`) เพื่อให้มือถือที่ติดตั้งแอปไว้โหลดเวอร์ชันใหม่

## หมายเหตุ

- ราคาต่อหน่วยตั้งต้นเป็นตัวเลขตัวอย่าง ไม่ใช่ราคาจากผู้ขาย ใส่ราคาของร้านก่อนใช้เสนอราคา
- การตรวจการชนที่มุมเป็นกล่อง 2 มิติแบบเผื่อปลอดภัย ไม่ใช่การจำลองฮาร์ดแวร์จริง ตรวจระยะและสเปกฮาร์ดแวร์ในแบบผลิตก่อนสั่งตัด
- ตัวคำนวณแปลงมาจาก BOQ-Cabinet Generator v4.9.0 (Blender add-on, GPL-3.0-or-later) และทดสอบผลตรงกับ add-on ในโหมดเทียบเคียง
- add-on ใน `blender/` อยู่ภายใต้ GPL-3.0-or-later ตาม `blender_manifest.toml`
